# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
pnpm dev              # Dev server on port 3000 (development)
pnpm dev:staging      # Dev server (staging env)
pnpm dev:prod         # Dev server (production env)
pnpm build            # Build (development)
pnpm build:staging    # Build (staging)
pnpm build:prod       # Build (production)
pnpm preview          # Preview build
pnpm test             # Run tests (vitest)
pnpm type-check       # TypeScript check
pnpm lint             # ESLint check
pnpm format           # Prettier write + ESLint fix
pnpm check            # Prettier check only
```

Run a single test file: `pnpm test src/path/to/file.test.ts`

## Stack

- **TanStack Start** (SSR React framework, Vite + Nitro under the hood)
- **TanStack Router** (file-based routing, route tree auto-generated)
- **React 19**, **TypeScript**, **Tailwind CSS v4**
- **shadcn/ui** (`radix-ui`, style `radix-vega`) — add components via `pnpm shadcn add <name>`
- **Vitest** + `@testing-library/react` for tests

## Import Alias

The import alias is `#/` (maps to `./src/`), configured in `package.json` `imports` field:

```ts
import type { Foo } from '#/models/foo.model'
```

> Not `@/`. The `components.json` references `@/` aliases but those are shadcn config; actual code uses `#/`.

## Routing

Routes live in `src/routes/`. TanStack Router generates `src/routeTree.gen.ts` automatically — **never edit this file manually**.

- Root layout: `src/routes/__root.tsx` (defines `<html>` shell)
- Router instance: `src/router.tsx`
- Index route: `src/routes/index.tsx`

## Architecture (Feature-Based)

```
src/
├── routes/              # TanStack Router pages (file-based)
├── features/            # Self-contained feature modules
├── shared/
│   ├── components/ui/   # shadcn-generated components — do not modify manually
│   ├── data/            # constants.ts, local-storage-keys.ts
│   ├── hooks/           # Global React hooks (use-*.ts)
│   ├── lib/             # api.ts, logger.ts, utils.ts
│   └── providers/       # React context providers
└── environments/        # Environment configs (dev/staging/prod)
```

### Feature Module Structure

Each feature in `src/features/{feature}/` is autonomous:

| File | Role |
|------|------|
| `*.service.ts` | API calls (uses `api` from `#/shared/lib/api`) |
| `use-*.ts` | React hooks (client state, mutations) |
| `*.types.ts` | Feature-specific types |
| `components/` | Feature-specific UI components |
| `index.ts` | Public barrel — only entry point for external imports |

### Placement Rules

| Creating... | Goes in... |
|-------------|-----------|
| Page/route | `src/routes/` |
| Shared UI component | `pnpm shadcn add <name>` → `src/shared/components/ui/` |
| Business component | `src/features/{feature}/components/` |
| Global hook | `src/shared/hooks/use-*.ts` |
| Feature hook | `src/features/{feature}/use-*.ts` |
| Feature API calls | `src/features/{feature}/*.service.ts` |
| Global constant | `src/shared/data/constants.ts` |
| Global provider | `src/shared/providers/` |

## Naming Conventions

| Type | Convention | Example |
|------|------------|---------|
| File (component) | `kebab-case.tsx` | `user-card.tsx` |
| File (hook) | `use-*.ts` | `use-users.ts` |
| File (service) | `*.service.ts` | `users.service.ts` |
| File (model) | `*.model.ts` | `user.model.ts` |
| Component export | PascalCase | `UserCard` |
| Hook export | camelCase | `useUsers` |
| Constant | SCREAMING_SNAKE_CASE | `TOKEN_VALIDITY_PERIOD` |

## Key Rules

- No `any` — use `unknown` or generics
- No `@ts-ignore` / `@ts-nocheck`
- Environment variables come from `#/environments` (never hardcoded)
- `src/shared/components/ui/` is shadcn-managed — do not edit manually
- Do not touch `src/routeTree.gen.ts` — auto-generated by TanStack Router
- TanStack Router redirects: `throw redirect({ to: '/' })` — not `Route.redirect()`
- Feature external imports only through `index.ts` barrel
